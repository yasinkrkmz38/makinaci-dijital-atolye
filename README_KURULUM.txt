DİJİTAL MAKİNACI V10
1) Klasörde CMD aç.
2) npm install
3) npm start
4) http://localhost:3000

GITHUB/RENDER:
- package.json, server.js ve public klasörünü GitHub reposunun köküne yükle.
- Aynı isimli dosyaların üzerine yaz.
- Commit changes yap.
- Render otomatik deploy eder.
- Alan adın: https://dijitalmakinaci.pro

Not: Teknik hesaplar ve teşhis akışları karar desteğidir; kritik limitlerde üretici dokümanı ve ilgili prosedür/standart esas alınmalıdır.
